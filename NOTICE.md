# Provenance

Karpotkin Coding Harness is a maintained distribution derived from
[Superpowers](https://github.com/obra/superpowers), originally created by Jesse
Vincent and contributors. The included `LICENSE` file preserves the required
MIT copyright and permission notice.

The DeepSeek Harness adapter is based on the public implementation and research
submitted by `codeAnqiang-ma` in Superpowers pull request #2144, adapted here
for the `karpotkin/coding-harness` distribution.

Repository history was intentionally started fresh. Provenance is recorded in
this notice rather than represented as a GitHub fork relationship.
